# 三欄一頁式資產異動表單

正式表單：<https://docs.google.com/forms/d/1_56JvacszRMvPIr4T5CEwtZpcheqw-r_s9_Qy41MxCo/edit>

使用者只需要填寫三題； Google Forms 自動產生的 `Timestamp` 與 `Email Address` 仍保留。

| 欄位 | 填寫方式 |
|---|---|
| 交易類型 | `標的／主體＋動作`，例如 `006208 買入`、`現金 存入`、`質押 利率` |
| 交易單位 | `張`、`股`、`台幣`、`美金`、`%` |
| 交易數量 | 只填非負數字；取代事件可填 `0` 清除目前數值 |

解析規則由 `simple_transaction.py` 固定 header mapping 處理，舊版表單仍由相容解析器處理。股票與基金缺少成交價時，系統使用當次結算行情估值；行情不存在、過期或只能使用 fallback 時，該筆會進入待確認，不會寫入正式帳本。

## 測試資料

- `006208 買入` / `張` / `1`
- `QQQM 賣出` / `股` / `3`
- `現金 存入` / `台幣` / `100000`
- `質押 借款` / `台幣` / `100000`
- `質押 利率` / `%` / `2.25`
- `006208 取代` / `股` / `2000`

表單只保留第一區段的提交路徑；舊區段與歷史回覆保留在原表單中，不會被刪除。無效標的、動作、單位或數量會進拒絕／待確認紀錄。
